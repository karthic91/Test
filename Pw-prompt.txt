PHASE 5 — Convert All Step Definitions to Playwright BDD

Migrate every existing Cucumber step definition to playwright-bdd.

Use the supported createBdd() API and Playwright fixtures.

Existing Protractor Example

import { Given, When, Then } from '@cucumber/cucumber';
import { browser } from 'protractor';
Given('user opens the application', async () => {
  await browser.get('https://example.com');
});

Target Playwright BDD Example

import { createBdd } from 'playwright-bdd';
import { test } from '../fixtures/test.fixture';
const { Given, When, Then } = createBdd(test);
Given('user opens the application', async ({ page }) => {
  await page.goto('/');
});

Adapt imports and configuration to the installed playwright-bdd version.
